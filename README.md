# FreshMart - E-Commerce Website

A modern e-commerce platform specializing in fresh food and groceries. The project includes a customer storefront and a comprehensive admin management dashboard.

## Deployment Links (Render)

* **Customer Storefront:** [https://freshmart-8gbr.onrender.com](https://freshmart-8gbr.onrender.com)
* **Admin Dashboard:** [https://freshmart-dashboard.onrender.com](https://freshmart-dashboard.onrender.com)


## Key Features

* **FreshMart Storefront (Client):** Browse by categories, product search, shopping cart, checkout, user authentication, and order history.
* **FreshMart Dashboard (Admin):** Revenue analytics charts, product management (CRUD), inventory tracking, order status updates, and user management.


## Tech Stack

* **Frontend:** React.js / Tailwind CSS
* **Backend:** Node.js (Express)
* **Database:** MongoDB / SQL
* **Hosting:** Render
